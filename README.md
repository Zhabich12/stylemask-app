# stylemask

Программа для Windows, которая переписывает твой текст так, чтобы по стилю письма нельзя было понять, что это написал ты. Все модели работают локально, текст никуда не отправляется.

По манере письма (пунктуация, словечки, длина фраз, заглавные буквы) человека можно узнать примерно как по почерку: это называется **стилометрия**. stylemask сохраняет смысл сообщения, но меняет манеру: делает её нейтральной или подстраивает под стиль другого человека.

> Проект на стадии исследования. Модель иногда искажает смысл, поэтому перечитывай результат перед отправкой.

## Как это выглядит

1. Пишешь сообщение в Telegram, браузере или где угодно.
2. Нажимаешь **Ctrl+Alt+Q**. В углу экрана появляется индикатор («Разбираю смысл (1/3) → Пишу (2/3) → Проверяю смысл (3/3)»).
3. Через 3–10 секунд текст в поле заменяется переписанным. **Ctrl+Alt+Z** возвращает как было.

Режимы:
- **Нейтрально.** Пишет как «средний» человек без характерных примет.
- **Как другой автор.** Подражает выбранному человеку: по его текстам строятся правила стиля и подбираются похожие по теме примеры.
- **Как другой автор + проверка.** После переписывания классификатор проверяет, узнаётся ли ещё твой стиль, и если да, модель переписывает заново с подсказками.

Стиль можно дообучать отзывами: «👍 похоже», «✏️ вот как он написал бы на самом деле», замечания вроде «никогда не ставит запятые».

## Как устроено

```
твой текст ─► заметки «что сказано» ─► сообщение в нужном стиле ─► проверка смысла ─► вставка
                                                (локальная LLM)        (повтор при искажении)
```

- `src/stylemask/rewrite.py`: переписчик (заметки → сообщение → проверка смысла), карточка стиля, подбор примеров.
- `src/stylemask/attribution.py`: четыре «угадывателя автора», которыми меряется качество маскировки: n-граммы, стиль без содержания, Burrows's Delta, морфология (части речи).
- `src/stylemask/hotkey.py`: горячие клавиши Windows. **Нажатия клавиш не записываются**: программа реагирует только на свои сочетания, по ним выделяет текст в поле, копирует, переписывает и вставляет, а потом восстанавливает буфер обмена.
- `src/stylemask/gui.py`: окно настроек, индикатор прогресса, отзывы.
- `scripts/experiment.py`: замер: переписывает тексты нескольких авторов и проверяет, различают ли их классификаторы.

Результаты экспериментов и ход работы описаны в [PROGRESS.md](PROGRESS.md).

## Установка

Нужно:
- Windows 10/11;
- [Python 3.11+](https://www.python.org/downloads/);
- [LM Studio](https://lmstudio.ai/) с моделями `qwen/qwen3.5-4b` (переписывание) и `text-embedding-nomic-embed-text-v1.5` (проверка смысла и подбор примеров). Хватит видеокарты на 4 ГБ.

```
git clone https://github.com/Zhabich12/stylemask-app
cd stylemask-app
git config core.hooksPath .githooks
py -m venv .venv
.venv\Scripts\pip install -e .
copy stylemask.example.toml stylemask.toml
```

В LM Studio скачай модели и включи сервер (вкладка Developer → Start Server).

## Стили (персоны)

В репозитории **нет никаких текстов**: ни переписок, ни датасетов. Стили собираются у тебя на компьютере в папке `data/`, которая в git не попадает.

- **Из своих чатов Telegram.** В Telegram Desktop: чат → ⋮ → «Экспорт истории чата» → HTML. Потом в программе «Настройки → Добавить стиль из Telegram…» или в консоли:
  `stylemask add-style <папка экспорта> --author "<имя>"`.
- **Комментаторы Пикабу** из открытого датасета [IlyaGusev/pikabu](https://huggingface.co/datasets/IlyaGusev/pikabu). Скачай один файл, например `00.jsonl.zst` (~1 ГБ), в `data/raw/` и выполни
  `stylemask build-pikabu data/raw/00.jsonl.zst`.

Подражать конкретному реальному человеку стоит осторожно: подозрение может упасть на него. Для анонимности надёжнее «нейтрально» или стиль незнакомого человека.

## Запуск

Двойной клик по `stylemask.bat` или `stylemask gui`. Командная строка:

```
stylemask rewrite "текст"                       # нейтрально
stylemask personas                              # список стилей
stylemask rewrite "текст" --persona tg:Имя      # как другой человек
stylemask experiment --method persona           # замер качества
```

## Приватность

- Переписывание идёт только через локальный сервер LM Studio. Клиент отказывается подключаться к нелокальному адресу, если это не разрешено явно.
- `data/` (переписки, датасеты, отзывы, журнал) исключена из git, а pre-commit хук блокирует случайные коммиты с переписками.
- Журнал `data/stylemask.log` пишет только события («взято 120 символов», «вставлено»), без текста.
